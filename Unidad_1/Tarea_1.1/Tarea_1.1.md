## 2. Fundamentos, Objetivos y Áreas de Aplicación 
### 2.1. Conceptos Clave  
* **Base de Datos (BD):** Colección estructurada de datos interrelacionados, organizada de manera lógica para permitir su almacenamiento, acceso y modificación eficiente. 
* **Sistema de Gestión de Bases de Datos (SGBD):** Software que actúa como interfaz entre la base de datos, las aplicaciones y los usuarios, garantizando el control de acceso y la integridad de los datos.

### 2.2. Objetivos Principales
1. **Control de Redundancia:** Minimizar la duplicación innecesaria de información. 
2. **Integridad de Datos:** Asegurar que los datos almacenados sean precisos y cumplan con las reglas de negocio.
3. **Independencia de Datos:** Aislar las aplicaciones de los cambios en la estructura física del almacenamiento.
4. **Acceso Concurrente y Seguridad:** Permitir el acceso simultáneo de múltiples usuarios garantizando consistencia y control de permisos.

### 2.3. Áreas de Aplicación 
* **Banca y Finanzas:** Registro de transacciones y cuentas en tiempo real.
* **Comercio Electrónico:** Gestión de inventarios, pedidos y clientes.
* **Salud:** Expedientes clínicos y administración hospitalaria.
* **Educación:** Control de alumnos, calificaciones y planes de estudio.
